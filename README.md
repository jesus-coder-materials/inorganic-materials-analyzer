**Inorganic Materials ** **Availability Checker** ** (IMACH)**  
A Python GUI application for analyzing crystallographic and optoelectronic properties of inorganic compounds using the Materials Project API.  
**Features**  
- Crystal Structure Analysis  
- Energy Band Gap (DFT vs Experimental)  
- Ionic Radius Assessment and Coordination Number, Pauling's Rules, and Grimm-Sommerfeld Rule  
- Support for elemental, binary, ternary, quaternary, and others compounds  
**Installation**  
1. Download the latest release  
2. Extract and run the .exe or .bin file  
3. Enter your Materials Project API key on first launch  
**Usage**  
1. Enter a chemical formula (e.g., GaAs, mp-149)  
2. Select the desired crystal structure  
3. Click "Analyze Phase"  
4. View results
